### Featured Project

**[C++ Packet Filtering Firewall](https://github.com/Haris-waseem/firewall)**

A multi-stage network packet inspection **simulation** built from scratch in C++17:
- Custom-built data structures (LinkedList, BST, HashMap, Stack, Queue) — implemented without STL containers
- SYN flood and port scan detection using sliding time-window algorithms
- Admin REPL CLI with 20+ commands for live configuration and monitoring
- Dual persistence layer — MongoDB with automatic CSV fallback
- 7-panel GUI dashboard built with Dear ImGui / ImPlot
- Dual launch modes: GUI (`./Firewall`) and CLI (`./Firewall --cli`)

Developed as a full multi-subject deliverable, backed by a complete SRS (180 functional requirements across 6 modules), SDS, and project scope documentation.
