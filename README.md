### 🔥 C++ Packet Filtering Firewall

A **multi-stage network packet inspection simulation** built entirely from scratch in C++17 — no frameworks, no STL containers for core logic.

**Architecture Highlights:**
- `O(1)` IP matching via custom **HashMap** (djb2 hashing + dynamic rehash)
- `O(log n)` priority-based rule evaluation via custom **BST**
- **7-panel GUI dashboard** built with Dear ImGui / ImPlot
- Dual launch: GUI (`./Firewall`) and CLI (`./Firewall --cli`)

</td>
<td width="50%" valign="top">

### 🛡️ Threat Detection & Operations

Real-time anomaly detection without third-party libraries:

- **SYN Flood Detection** — sliding time-window tracking of TCP SYN packets per source IP
- **Port Scan Detection** — horizontal scan identification by monitoring distinct target ports
- **20+ Admin REPL commands** for live firewall configuration
- **Dual persistence** — MongoDB with automatic CSV fallback
- Backed by complete **SRS** (180 functional requirements) and **SDS** documentation

</td>
